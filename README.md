# 📊 Tender Management Dashboard

## 📌 Project Overview

The Tender Management Dashboard is an interactive financial and operational reporting solution developed using Microsoft Excel.

This dashboard helps monitor tender performance, company-wise financial activities, bill collections, expenses, employee salaries and contract-related information in one centralized view.

## 🎯 Project Objectives

* Monitor company-wise and tender-wise financial performance.
* Track RA bills, received amounts and pending collections.
* Monitor salary payments and outstanding balances.
* Analyze tender-related expenses and profitability.
* Track supervisor fund utilization and balances.
* Monitor Fixed Deposit Receipts (FDR) and Bank Guarantees (BG).
* Track contract commencement, completion and extension dates.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Advanced Excel Formulas
* SUMIFS, VLOOKUP, MAXIFS and IFERROR
* Data Validation & Dropdown Filters
* Excel Charts & Interactive Dashboard

## 📈 Dashboard Features

* Company-wise and Tender-wise Analysis
* Monthly Reporting Filters
* RA Bill Collection & Pending Amount Tracking
* Bank Balance Monitoring
* Salary Transfer & Pending Salary Analysis
* Expense Tracking & Profitability Analysis
* Supervisor Account Monitoring
* FDR & BG Tracking
* Contract Timeline Monitoring

## 📂 Workbook Structure

| Sheet Name          | Purpose                                         |
| ------------------- | ----------------------------------------------- |
| Dashboard           | Centralized reporting and analysis              |
| Company Master Data | Company information                             |
| Tender Master Data  | Tender details and contract information         |
| RA Bill Tracker     | Bill collection and pending payments            |
| Expense Tracker     | Tender-wise expense tracking                    |
| Supervisor Tracker  | Supervisor fund management                      |
| Salary Tracker      | Employee salary tracking                        |
| FDR-BG Tracker      | Financial security tracking                     |
| Bank Transactions   | Bank credit and debit monitoring                |
| Helper Sheet        | Dashboard dropdowns and supporting calculations |
